# Frontend Mentor lessons and challenges

My solutions to [Frontend Mentor](https://www.frontendmentor.io/profile/gitguerz) challenges, one folder per challenge. Everything here is HTML and CSS only for now.

Live at [frontend.guerz.lol](https://frontend.guerz.lol/).

## Challenges

| Challenge | What I practiced | Code | Live |

## How the repo is laid out

Each challenge folder has its own `index.html`, `styles.css`, `README.md`, and images. The folder README has the details for that challenge: what I built, what I learned, and what I'd change.
